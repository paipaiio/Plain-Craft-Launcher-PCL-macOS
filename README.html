Plain Craft Launcher (PCL) macOS

这是第三方基于 Plain Craft Launcher 独立进行二次创作的 macOS 原生重构工程，不是官方 PCL。原作作者为龙腾猫跃，源码发布时保留原项目 LICENCE 指南与署名说明。

SwiftUI AppKit macOS 14+ Native Shell

授权与署名

本项目属于原 LICENCE 中的重度使用：它重新实现了 PCL 的 Minecraft 启动、下载和 Mod 管理等实质功能。因此仓库、应用关于页和文档均明确标注第三方二创身份，并保留原作者署名。

运行

cd PCLMac
swift run PCLMac

构建 .app

cd PCLMac
chmod +x Scripts/build-macos-app.sh
Scripts/build-macos-app.sh
open "dist/Plain Craft Launcher (PCL) macOS.app"

如果 /Applications 里已有同名旧包，请优先使用上面的 dist/Plain Craft Launcher (PCL) macOS.app 路径打开；进入「更多 → 关于」可确认当前运行位置并复制完整路径。

安装到 Applications

打包脚本默认不会覆盖系统应用目录。确认要更新正式安装包时，显式加 --install；若目标位置已有同名 app，会先备份成带时间戳的 .backup 包，再安装新构建。

cd PCLMac
Scripts/build-macos-app.sh --install
open "/Applications/Plain Craft Launcher (PCL) macOS.app"
安装到自定义目录 
cd PCLMac
Scripts/build-macos-app.sh --install --install-dir "$HOME/Applications"

正版登录

mac 版按 PCL 原版的 6 步链路实现 Microsoft 登录。登录成功后会把 Minecraft access token、refresh token、UUID 和玩家名保存到 Keychain 与账户库，启动游戏时使用 userType=msa 和正版 access token。

步骤 接口
1Microsoft device code / token / refresh token
2Xbox Live user authenticate
3XSTS authorize
4Minecraft login_with_xbox
5Minecraft entitlements mcstore
6Minecraft profile
Client ID 是什么

client_id 是 Microsoft 应用注册的公开应用编号，用来告诉 Microsoft “正在请求授权的是哪个启动器应用”。它不是用户密码，也不是 client secret。mac 版会优先使用设置页的高级覆盖值，其次读取运行环境的 PCL_MS_CLIENT_ID，最后读取 app 包内置的 PCLMicrosoftClientID；正式分发包应在打包时内置它，普通用户不需要自己填写。

PCL_MS_CLIENT_ID="你的 Microsoft 应用 Client ID" Scripts/build-macos-app.sh
plutil -p "dist/Plain Craft Launcher (PCL) macOS.app/Contents/Info.plist" | grep PCLMicrosoftClientID

Authlib 登录

Authlib 入口按 PCL 的 Yggdrasil 服务器流程实现。启动页登录卡片可直接填写认证服务器、账号和密码；登录成功后保存角色、access token、client token；启动前会按当前登录模式选择 Authlib 账户，尝试 validate，失败后 refresh，再失败时使用 Keychain 中的密码重新 authenticate。

项目 说明
服务器 可以填写皮肤站根地址或 /authserver 地址，启动器会规范到认证端点。
角色 多角色账户会优先使用上次缓存的 UUID，否则选择服务器返回的第一个角色。
启动 启动前下载并校验 authlib-injector.jar，然后添加 -javaagent、authlibinjector.side 和 prefetched 元数据。

安装流程
  1. 打开「下载」页，等待版本列表加载完成。
  2. 如果要使用非默认游戏目录，先到「设置 → 系统 → 路径」选择 Minecraft 根目录。
  3. 用「正式版 / 快照版 / 全部」筛选，也可以直接搜索版本号。
  4. 在「加载器」里选择「原版」「Forge」「Fabric」「Quilt」或「NeoForge」。
  5. 选中版本后点击「安装版本」。完成后会自动回到「启动」页并刷新本地实例。
  6. 安装、下载和整合包导入过程中可打开「下载 → 任务」查看统一任务记录、复制任务摘要和打开 Finder 位置。
  7. 需要单独调整某个版本时，在启动页点击版本卡片里的滑杆按钮，进入「设置 → 版本」配置 Java、内存和高级参数。
  8. 可以先在启动页的「依赖补全」卡片点击「预补全」，即使还没登录也能提前下载基础资源；点击「启动游戏」时仍会兜底检查依赖，然后执行 Java 命令。

联机

联机页会监听 Minecraft Java 版局域网广播。对方在游戏内选择“对局域网开放”后，启动器可以在「联机 → 房间」扫描到世界名称和端口，并把房间地址复制出来、写入启动服务器设置，或收藏到「联机 → 连接信息」的常用服务器列表。启动页左侧也会显示当前自动进服目标，可直接从常用服务器启动并进服。

局域网房间流程
  1. 同一网络内的主机玩家在 Minecraft 暂停菜单中打开“对局域网开放”。
  2. 在启动器打开「联机 → 房间」，点击「扫描」。
  3. 选中发现的房间后，可以复制 host:port，也可以点击「设为启动服务器」或「收藏到常用服务器」。
  4. 设为启动服务器后，启动器会把主机地址和端口写入全局自动进服设置，下一次启动当前实例时自动附加 --server 和 --port。
常用服务器模板 
{
  "name": "Hypixel",
  "address": "mc.hypixel.net",
  "port": null
}

常用服务器会保存到偏好设置里；选中后可一键复制地址、写入全局启动服务器设置，或直接启动当前实例并进入该服务器。
